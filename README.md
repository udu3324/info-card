# Info Card PCB

A pcb in the shape of a standard size credit card with nft reading/writing capabilities, contact information, and useful references on the back. It is **fully designed in KiCad** instead of EasyEDA with symbols/footprints sourced from Ultralibrarian. 

## Why I Made It

I wanted to take a notch down on all the highly complicated PCBs I've made and create something more artsy.
